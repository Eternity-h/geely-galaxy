# 吉利银河 Home Assistant 集成

将吉利银河车辆接入 Home Assistant 的自定义集成：状态监控、远程控制、充电管理、每日签到。

> **本项目是 [lyj5812/geely-galaxy](https://github.com/lyj5812/geely-galaxy) 的独立维护分支。**
> 上游自 2026-08 起未再更新（3 个 issue 均无回复）。本分支在其基础上修复了若干影响可用性的
> 缺陷，并以自己的节奏发布。原始代码版权归上游作者所有，许可证见 [LICENSE](LICENSE)。

## 功能

- **状态监控** —— 电量、续航、总里程、车内/外温度、PM2.5、平均能耗、车锁与空调状态
- **远程控制** —— 锁车/解锁、闪灯鸣笛寻车、车窗关闭与微开、空调、除霜、空气净化
- **充电管理** —— 充电状态/功率/电压/电流、历史充电记录、家用充电桩
- **其他** —— 哨兵模式、预约充电、每日签到

## 支持车型

- **银河星舰7 EM-i** —— 本分支实测可用
- **吉利银河 L7 / geely2 平台** —— 上游声明支持

车型不同，可用实体会有差异。走 XCHANGER 通道的车型（如 L7）会额外注册油量、燃油续航、四轮胎压等传感器，但不会注册哨兵模式与预约充电。

## 安装

### 通过 HACS（推荐）

本集成**不在 HACS 默认列表中**，需要作为自定义存储库添加：

1. 确保已安装 [HACS](https://hacs.xyz/)
2. 打开 HACS → **集成** → 右上角 ⋮ → **自定义存储库**
3. 填入 `https://github.com/Eternity-h/geely-galaxy`，类型选 **Integration**
4. 搜索「吉利银河」并下载
5. 重启 Home Assistant

### 手动安装

把 `custom_components/geely_galaxy/` 整个目录复制到 Home Assistant 配置目录下的 `custom_components/`，然后重启。

> ⚠️ **两种方式不要同时用。** HACS 和手动安装写入的是同一个目录，同时管理会互相覆盖。

## 配置

进入 **设置 → 设备与服务 → 添加集成**，搜索「吉利银河」。

### 登录方式

| 方式 | 说明 |
|---|---|
| **短信验证码** | 输入手机号 → 完成滑块验证 → 输入收到的验证码（推荐） |
| **Token** | 需自行抓包获取 `refresh_token` 与 `device_sn` |
| **密码** | 需提供 SM4 加密后的密码 |

## ⚠️ 使用须知

**账号单会话（最重要）**
吉利账号同一时间只允许一个活跃会话。集成按固定间隔轮询（默认 60 秒），**可能导致手机 App 被顶下线**。若遇到这种情况，把扫描间隔调大：

编辑 `custom_components/geely_galaxy/const.py`：

```python
DEFAULT_SCAN_INTERVAL = 300   # 建议 ≥300，默认 60
```

改完重启 Home Assistant。间隔越大越不容易顶号，代价是状态刷新变慢。

**签名密钥**
集成内置的 App 签名密钥提取自官方 App。若吉利轮换密钥，集成会失效，需等待更新。

**账号风控**
高频调用可能触发服务端限流。不要把扫描间隔设得过小。

**凭据存储**
登录后的 refresh token 保存在 HA 的配置条目中（明文，与多数 HA 集成一致）。请注意 HA 配置目录的访问权限。

## 故障排查

遇到问题请：

1. 查看 HA 日志（**设置 → 系统 → 日志**），筛选 `geely_galaxy`
2. 到 [Issues](https://github.com/Eternity-h/geely-galaxy/issues) 提问

> ⚠️ **提问前请先检查日志里有没有 token。** 本分支已修复 token 入日志的问题（1.0.1 起），但历史版本、或开启 DEBUG 日志时仍可能打印含凭据的内容。贴日志前请自行确认。
